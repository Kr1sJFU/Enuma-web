# Residential Street — interactive prototype

Open `index.html` to review the three-turn experience. The supplied clean silent 1248×720, 16 fps sequence is preserved without re-encoding. Its turn boundaries are frames 0, 129, 258, and 387 (0, 8.0625, 16.125, and 24.1875 seconds). `../build.py` packages the master, poster, and EDL.

The compact action button, `W` / `E` / `E` shortcuts, and clickable `01`–`03` bars play the prerecorded turns. `R` restarts. These keys are editorial playback cues based on visible actions, not a claim about the model's original conditioning prompts. No branches or live inference are implied.
